# D02 — AeroFleet X200 Cooling Subsystem Maintenance Manual, Issue v2.1
Document type: Maintenance manual  
Status: CURRENT AUTHORITATIVE VERSION  
Effective date: 2026-01-15  
Supersedes: Issue v1.4

This is the current maintenance authority for routine inspection intervals of the cooling subsystem.

Routine inspection intervals:
- Inspect **fan assembly** every **80 flight cycles** or every **30 calendar days**, whichever comes first.
- Inspect **pump filter** every **160 flight cycles**.
- Inspect temperature sensor harness whenever a fan assembly replacement is performed.

Diagnostic thresholds:
- If **fan current imbalance** exceeds **0.6 A** for **three consecutive samples**, perform an inspection.
- If **Pack-ΔT** exceeds **8 °C** in stabilized cruise, inspect for airflow restriction or pad contact loss.

Maintenance note:
Before replacing a fan, technicians should first verify connector seating and blade contamination.  
Do not use procurement notices or archived manuals to override the intervals in this document.
