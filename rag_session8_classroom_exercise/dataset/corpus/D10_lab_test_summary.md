# D10 — Lab Test Summary: Charger Bench Evaluation
Document type: Lab test summary  
Status: Reference  
Effective date: 2026-02-14

Bench tests on the revised charger showed:
- Fast charging is stable when battery core remains below **45 °C**
- Pack balancing becomes less reliable when Pack-ΔT exceeds **8 °C**
- Fan asymmetry alone is not enough to diagnose a thermal event; context from flow and temperature is required

This summary is useful as supporting evidence, but operational thresholds must still be checked against the active maintenance manual and service bulletin.
