# D05 — Incident Report IR-04: Pre-Runaway Venting Precursor Event
Document type: Field incident report  
Status: Case evidence  
Effective date: 2026-02-28

Summary:
Aircraft X200-17 experienced an abnormal thermal event during post-mission charging.  
No full thermal runaway occurred, but investigators classified the event as a **cell venting precursor**.

Observed sequence before pack isolation:
- Battery core temperature reached **51.6 °C**
- Pump flow estimate dropped by **18%**
- Left-right fan current difference increased to **0.7 A**
- Pack-ΔT rose to **9 °C**
- Operator noted a faint solvent-like odor near the charging rack

Engineering interpretation:
The event did not become an open flame case.  
However, the combination of **high core temperature**, **reduced coolant flow**, **fan current asymmetry**, and **large temperature spread** was treated as an early warning pattern for thermal escalation.
